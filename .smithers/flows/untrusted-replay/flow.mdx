# Isolated Community Sandbox Replay

1. Verify that no host secrets, write tokens, or maintainer credentials enter the sandbox.
2. Allow read-only access to the shared Smithers Cloud object store (`https://build.smithers.sh`) for fast warm cache hits.
3. Run `bun run audit:untrusted` and store the resulting Lighthouse report strictly under `untrusted/<actor>/<sha>/`.
4. Return the preview score and diagnostics clearly labeled `UNTRUSTED COMMUNITY`.
